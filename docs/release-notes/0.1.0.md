# C30 Super Login 0.1.0 Preview

保存账号，课前快速登录。本版重点是登录基础、账号档案和原生桌面界面。

## 新增
- Avalonia / FluentAvalonia 界面，支持浅色、深色和跟随系统。
- 五步首次引导：左侧步骤导航、卡片式运行选择、读取 / 新建账号和常用设置，可直接配置并导出 ClassIsland 任务。
- 设置可切换「后台常驻 / 仅调用时运行」。连接 C30 必须正常申请管理员权限，不再提供关闭选项。
- 新绘 C 形入口图标；关于页「相关链接」使用两个项目自己的图标并说明用途，未开放在线更新时使用简短提示。
- 自动保存账号、读取 C30 已记住的账号、重复合并；数字 ID 从 1 开始，ClassIsland / 自动化直接填写 `--id 1`。旧长 ID 保持兼容。
- 优先注入；明确未提交时尝试页面控件；两种自动方式都未成功时提示手动登录。
- 自动登录前可倒计时提醒、跳过本次或推迟一分钟。手动登录不加倒计时。
- 每次操作前重新识别 C30 安装位置和本机版本，区分运行版和已安装版。
- 接入 Velopack 官方更新 SDK：后台检查、主动下载、手动重启应用更新；登录或提醒进行中拒绝重启。
- 两项上报默认开启，切换登录方式会记录方式、原因、顺序、耗时和 C30 版本，不包含账号密码。

## 下载与使用
推荐下载 `C30SuperLogin-Setup.exe`。安装包自带运行环境；原有开发 ZIP 仍需 .NET 10 Desktop Runtime。
安装后打开 C30 的账号登录页，再在助手「连接与诊断」检查连接。
